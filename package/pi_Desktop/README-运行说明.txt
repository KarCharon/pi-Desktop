Pi Desktop Windows 便携版

启动：
- 双击 bin\pi_Desktop.exe。
- 也可以运行同目录下的 install-folder-menu.cmd 安装文件夹右键菜单。

本包包含当前项目运行所需的：
- pi_Desktop.exe
- Qt 运行库、QML 模块和插件
- MinGW 运行库
- 文件夹右键菜单脚本

本包不包含：
- Node.js、Pi CLI 或其他 npm 依赖
- Pi Profile、认证信息、会话记录
- 项目源代码和用户工作目录

说明：
- 仅支持 Windows 64 位。
- 请整体复制或解压 package/pi_Desktop 目录，不要只复制 exe 文件。
- 运行聊天功能时，目标电脑需要自行安装 Node.js 和 Pi CLI，并确保 pi 命令位于 PATH，或在应用设置中填写 Pi 可执行文件路径。
